# 🎨 Intro to CSS

A beginner-friendly HTML & CSS project demonstrating different CSS selectors and styling techniques.

## 🚀 Features
- Element Selector
- Class Selector
- ID Selector
- `:first-child`
- `:nth-child()`
- Child Selector
- Span Tag Styling
- Ordered & Unordered List Styling

## 🛠️ Technologies Used
- HTML5
- CSS3

## ▶️ How to Run
Open `index.html` in your browser.
