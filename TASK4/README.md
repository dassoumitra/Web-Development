# HTML Image Section Project

This project is created using HTML and CSS.  
It displays an image with a button below it using proper spacing, viewport units, and box-sizing properties.

---

## Features

- Image displayed inside a div
- Gradient styled button
- Equal left and right spacing
- Top and bottom spacing maintained
- Uses ViewPort units (`vw`, `vh`)
- Uses `box-sizing: border-box`
- No Flexbox used
- No `overflow:hidden`
- No `position: relative` or `absolute`
